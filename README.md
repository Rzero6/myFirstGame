# 🎮 3D Bounce-Inspired Platformer

This project is a 3D platformer game inspired by the classic Bounce. Built as my first Unity game development practice project — focusing on basic gameplay mechanics, scoring, and level completion.

---

## 🛠 Tech Stack
- Unity (C#)
- Windows Build Target

---

## 🎯 Game Features
- 🏀 Bounce-like movement in 3D environment  
- 👾 Enemy AI — avoid or lose health  
- ❤️ Health system  
- ⏱ Timer to track level completion time  
- ⭐ Point system for player scoring

## ▶️ How to Play
- Move and navigate through obstacles  
- Avoid enemies to maintain health  
- Collect points to get to the next level
